# 内容丰富度升级方案 — 从"能用"到"想收藏"

> 现状诊断（用户反馈：页面可以，但**内容单调、感觉一般**）
> 根因不是代码，而是**内容本身还停留在"素材清单"层**：缩略视觉同质、
> demo 场景雷同、文案偏通用、页面节奏单一（标题 + 网格轰炸）、
> 缺少叙事层（趋势/更新/教学/案例/真人语境）。

---

## 1. 诊断：单调的 6 个来源（逐个给解药）

| # | 单调来源 | 观感问题 | 解药（对应下面的 Pillar） |
|---|---|---|---|
| 1 | 缩略/封面无辨识度 | 每个卡片都是"暗底 + 光斑"，滚 5 屏分不清谁是谁 | **Pillar A — 色彩指纹 + 封面系统** |
| 2 | demo 是"素材孤岛" | 组件没有放在真实页面语境里，看不出"装上去什么样" | **Pillar B — 场景剧场（context theater）** |
| 3 | 文案是清单式 | 标题+一句话+标签，没有设计决策、没有使用场景 | **Pillar D — 编辑声音（editorial voice）** |
| 4 | 版面节奏单一 | grid 一拉到底，没有强弱、没有"翻杂志"的节奏 | **Pillar E — 首页叙事编排** |
| 5 | 缺少生命感 | 没有"本周新增 / 趋势榜 / 谁在用 / 怎么一步步做出来" | **Pillar E — 运营层内容流** |
| 6 | 数量与品类单薄 | 品类才 4 类，形不成"图书馆"的厚实感 | **Pillar C — 内容目录化 + 数据驱动排产** |

## 2. 内容质量红线（每个上架素材必须满足）

1. **3 秒 wow**：打开 demo 前 3 秒有一个可描述的视觉瞬间（"光从左扫过去""点一下水波扩散"）。
2. **色彩指纹**：每个素材带唯一 accent hue + 专属背景氛围，缩略图阶段即可辨认。
3. **上下文示范**：demo 必须展示"装进真实页面长什么样"，不许只有孤零零的素材。
4. **文字层示范**：demo 里要示范排版（大标题/小标签/正文层级），让用户抄完不瞎。
5. **可描述可搜索**：一段"它解决什么、何时不该用"的人话，不是形容词堆砌。
6. **审计可见**：a11y / 体积 / 依赖 / 浏览器 / 降级策略照旧公开。

## 3. 六大 Pillar

### Pillar A — 素材身份系统（identity）
- **每素材一色**：slug 哈希映射到稳定 hue + 配套氛围色板（近邻色/对比色），卡片、详情、合集、OG 图全部继承。
- **封面系统**：每个素材出 3 档封面 —— `poster`（宣传位大图）、`tile`（列表小图）、`context`（真实页面截图）。
  - 自产素材 = 沙箱渲染自动截图（自带排版示范的 demo 就是封面，不再单配图）。
  - 艺术向背景 = 自建参数化生成器（seed → 独一无二的图，可再生、可分享）。
- **每素材配 2–4 个变体 preset**（配色/参数预设），Playground 一键切换——同素材变体多样，反单调成本最低。

### Pillar B — 场景剧场（context theater）
给素材配"舞台"，而不是放大镜：
- demo 内嵌**微型真实语境**：Tilt Card 出现在一个迷你定价页；Button 出现在一行 CTA + 输入框里；Loader 出现在"保存中"的编辑界面里。
- 新增 demo 品类（目标目录）：
  - **叙事滚动类**：滚动驱动故事（同步进度/分段揭晓）
  - **生成艺术类**：噪点/元胞自动机/分形/声波——每个都唯一、可截屏做封面
  - **数据小件**：count-up、迷你图表、走马灯数字、环形进度
  - **光标剧场**：spotlight、斥力、轨迹、磁吸（但保持低调可关）
  - **纯 3D CSS**：翻卡、轨道、景深堆叠（零依赖）
  - **文字编排**：巨字渐变、逐字揭晓、滚动换词、text-mask
- 每类保证 ≥ 3 个不同风格实例，避免"同款换皮"。

### Pillar C — 目录化 + 数据驱动排产
- 首发目录目标（先厚后精）：
  - Elements 400+ / Animated 180+ / Sections 120+ / Templates 30+ / Backgrounds 200+
  - Prompts 600+（30 行业 × 多栈 × 3 变体）；每份必须带实测 run log
- **趋势雷达**：按 copies/saves/收藏回流排"下周补什么"（后台已有雏形：copies by category）。
- 内容管线：原创设计规范 → AI 初稿 → 人工视觉评审 → 自动审计 → 语境截图 → 编辑文案 → 上线；
  目标是**每周 ≥60 素材 + 30 Prompt** 不掉链。

### Pillar D — 编辑声音（editorial voice）
- 每素材必填**三句话结构**：`它能干嘛 → 它怎么想出来的 → 它什么时候不该用`。
- 反空洞文案词表（禁用）：stunning/beautiful/awesome/modern/sleek 单独出现；
  用**可验证的表述**代替（"60fps 背景，0 JS" > "超流畅背景"）。
- 命名风格：动词开头/具象名词（Wipe Reveal、Halo Button、Orbit Deck），不叫 Component-42。
- Prompt 不只给"要做个官网"，给**设计决策 + 失败规避 + 评分依据**（现有 run log 是差异化，继续加厚"为什么这么设计"）。

### Pillar E — 首页叙事编排（翻杂志节奏）
页面节奏从"网格 × N"改成**强弱交替**（每屏一种模式）：
1. Hero（大字 + 实机剧场）
2. **一句话钩子 + 本周头条素材**（大图 editorial，非小卡）
3. **趋势榜**（本周最高分 Prompt / 最热素材，数字编号，带环比）
4. 分类导航（少量大卡）
5. **Editor's picks**（编辑手写一句推荐理由 —— 真人味）
6. **Made with Motif** 画廊（社区实站截图 + "看源码"）
7. **Change Log**（本周上了什么，日期 + 类别徽章，让站"活着"）
8. 教学路径 teaser（"花 20 分钟做一个会动的落地页"第 1 课免费）
9. 定价/CTA
> 叙事内容来源：真实用户投稿、内部 Build log、每周精选评审会记录。

### Pillar F — 真实感与信任
- **原创视觉素材**：自建纹理/艺术生成器（seed 可复现）+ AI 辅助原创场景，绝不复用竞品图。
- **"Built with Motif"社区画廊**（对标"谁在用"），每张卡片 = 真实部署链接 + 用到的素材清单 —— 反向激活社区。
- **教学与 SEO 内容**：以"问题"组织（"hero 总是死气沉沉？"），每篇带可运行片段，形成长尾流量 + 留存（现有 /lab 与 learn 骨架接到这）。

## 5. 验收口径（不再"感觉一般"）
- 盲测：把 6 张 tile 缩略给路人看，能不能说出各自是什么（色彩指纹生效）。
- 每个素材详情页能回答"我装上它的页面长什么样"（语境剧场生效）。
- 首页滚 5 屏出现 ≥4 种不同版式节奏（叙事编排生效）。
- 单素材平均停留 >40s、收藏率 >3%（内容有钩子）。
- "Made with Motif"首月 50+ 实站（真实感生效）。
